# 登录 UI 交互流程

## 概述

应用使用 GitHub Device Flow 进行用户认证，无需 Client Secret，适合桌面应用。

## 交互流程

```
┌─────────────────────────────────────────────────────────────────┐
│                        用户点击登录按钮                           │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│              弹出验证码模态框（焦点保持在应用内）                    │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │                    输入验证码                            │   │
│  │  ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐      │   │
│  │  │ A │ │ B │ │ C │ │ - │ │ 1 │ │ 2 │ │ 3 │ │ 4 │      │   │
│  │  └───┘ └───┘ └───┘ └───┘ └───┘ └───┘ └───┘ └───┘      │   │
│  │                                                         │   │
│  │              [ 复制验证码 ]                              │   │
│  └─────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼ 用户点击"复制验证码"
┌─────────────────────────────────────────────────────────────────┐
│     1. 验证码复制到剪贴板                                         │
│     2. 关闭验证码模态框                                           │
│     3. 打开外部浏览器（GitHub 授权页面）                           │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼ 用户在浏览器中完成授权
┌─────────────────────────────────────────────────────────────────┐
│                    后台轮询检测授权状态                            │
│                    授权成功后发送事件                              │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│                    应用更新用户状态                                │
│              显示用户头像，右侧栏显示星标仓库                        │
└─────────────────────────────────────────────────────────────────┘
```

## 关键设计点

### 1. 焦点管理

- 点击登录后，焦点保持在应用内，不自动跳转到浏览器
- 用户主动点击"复制验证码"后才打开浏览器
- 用户有足够时间查看和记住验证码

### 2. 验证码展示

- 每个字符独立显示在方框中，清晰醒目
- 验证码自动复制到剪贴板
- 模态框有高 z-index 和不透明背景，确保视觉层级正确

### 3. 窗口控制

- 应用使用无边框窗口（Frameless）
- 窗口控制按钮（最小化、最大化、关闭）位于 header 右侧
- Header 区域可拖拽移动窗口
