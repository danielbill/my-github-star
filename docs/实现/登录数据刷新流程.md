# 登录数据刷新流程

## 概述

登录成功后，应用需要从 GitHub API 获取用户的星标仓库并保存到本地数据库。本文档描述数据刷新的完整流程。

## 数据刷新流程

```
┌─────────────────────────────────────────────────────────────────┐
│                    用户完成 GitHub 授权                           │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│              后端发送 login-success 事件                          │
│              携带用户信息（id, login, name, avatar_url）          │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│              前端收到 login-success 事件                          │
│                                                                  │
│   ┌─────────────────────────────────────────────────────────┐   │
│   │  步骤1: 强制刷新星标仓库（ForceRefreshUserStarRepo）       │   │
│   │  - 忽略缓存，直接调用 GitHub API                          │   │
│   │  - 获取用户所有星标仓库                                    │   │
│   │  - 计算新增星标数（stars_since）                          │   │
│   │  - 保存到本地数据库                                        │   │
│   └─────────────────────────────────────────────────────────┘   │
│                          │                                       │
│                          ▼ 等待完成                              │
│   ┌─────────────────────────────────────────────────────────┐   │
│   │  步骤2: 更新前端状态                                       │   │
│   │  - setIsLoggedIn(true)                                   │   │
│   │  - setUser(userData)                                     │   │
│   └─────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│              StarredSidebar 监听到 isLoggedIn 变化                │
│                                                                  │
│   ┌─────────────────────────────────────────────────────────┐   │
│   │  调用 LoadUserStarRepo() 从数据库读取数据                  │   │
│   │  - 此时数据库已包含最新数据                                │   │
│   │  - 显示星标仓库列表                                        │   │
│   └─────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
```

## 两种刷新模式

### 1. 强制刷新（ForceRefreshUserStarRepo）

**触发时机：** 登录成功后

**特点：**
- 忽略缓存计时器
- 直接调用 GitHub API
- 100% 执行数据更新

**代码位置：** `backend/app.go`

```go
func (a *App) ForceRefreshUserStarRepo() ([]models.Repository, error) {
    return a.refreshUserStarRepoWithForce(true)
}
```

### 2. 普通刷新（RefreshUserStarRepo）

**触发时机：** 
- 定时刷新
- 用户手动点击刷新按钮

**特点：**
- 检查缓存计时器
- 在刷新间隔内返回缓存数据
- 超过间隔才调用 GitHub API

**代码位置：** `backend/app.go`

```go
func (a *App) RefreshUserStarRepo() ([]models.Repository, error) {
    return a.refreshUserStarRepoWithForce(false)
}
```

## 时序关键点

```
时间线 ──────────────────────────────────────────────────────────▶

登录成功事件
    │
    ├── ForceRefreshUserStarRepo() 开始
    │       │
    │       ├── 调用 GitHub API
    │       ├── 处理数据
    │       └── 写入数据库
    │
    ├── ForceRefreshUserStarRepo() 完成 ✓
    │
    ├── setIsLoggedIn(true)  ← 此时数据库已有新数据
    │
    └── StarredSidebar 触发 LoadUserStarRepo()
            │
            └── 从数据库读取最新数据 ✓
```

**重要：** 必须先完成数据刷新，再更新 `isLoggedIn` 状态，否则 `StarredSidebar` 会读取到旧数据。
