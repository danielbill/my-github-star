# 项目详情窗口设计

## 功能概述

点击项目卡片时：
1. 在当前窗口内跳转到详情页（使用简化的 header）
2. 同时打开 Edge 浏览器访问项目的 GitHub URL

## 窗口布局

```
┌─────────────────────────────────────────────────────┐
│  项目名称                    [─][□][×] │  ← 简化 header (50px)
├─────────────────────────────────────────────────────┤
│  基本信息区 (200px)                                  │
│  - 名称、描述                                        │
│  - 星标数、统计数据                                  │
│  - 语言、创建/更新时间                               │
├─────────────────────────────────────────────────────┤
│                                                     │
│  下方区域（预留，暂时空白）                           │
│                                                     │
└─────────────────────────────────────────────────────┘
```

## 实现方案

### 前端 (React)

1. 创建 `DetailLayout` 组件
   - 简化 header，只有最小化/放大/关闭按钮
   - 左侧显示项目名称

2. 修改 `ProjectDetail` 页面
   - 使用新布局
   - 上方 200px 显示基本信息
   - 下方预留空白区域

3. 修改 `ProjectCard` 点击逻辑
   - 跳转到详情页路由
   - 同时打开 Edge 浏览器
