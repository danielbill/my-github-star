# github-news 技术栈

## 一、核心基座

- **Wails v2**：全栈桌面应用框架（Go + 前端绑定、窗口管理、打包分发）

## 二、后端（Go 语言）

- Go 1.21+
- 官方 GitHub SDK：`google/go-github`
- HTTP 客户端：Go 标准库 `net/http`
- JSON 处理：Go 标准库 `encoding/json`

## 三、前端

- 框架：React 18
- 语言：TypeScript
- UI 组件库：**Mantine**（全部页面组件）
- 样式：原生 CSS
- 构建工具：Vite（Wails 内置）
- 通信：Wails 自动生成的 TS 绑定（直接调用 Go 函数）

## 四、构建 / 打包 / 运行环境

- Windows 开发依赖：Go + Node.js + WebView2
- 打包命令：`wails build`
- 输出：**单文件 .exe**（无依赖、直接分发）
