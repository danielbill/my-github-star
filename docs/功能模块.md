# github-news 功能模块梳理

## 展示层（Wails 前端・Mantine 实现）

- 主界面 / 布局：基础窗口布局，响应式适配 Windows 桌面窗口，刷新按钮，搜索框
- GitHub 登录模块：登录入口，登录授权弹窗，登录状态展示，未登录提示，退出操作
- 配置AI服务，以便调用AI总结
- 项目列表模块：展示快速崛起的 GitHub 项目（名称、星数、描述、语言），项目排序，空状态 / 加载状态展示
- 项目详情模块：单个项目完整信息展示，周、月star增速，发布更新等，关联新闻 / 视频列表展示，关注，fork，clone
- 新闻 / 视频展示模块：关联新闻列表展示，视频链接跳转（可选）
- AI 总结展示模块：项目 AI 总结文本展示，总结加载态 / 异常提示
- 关注项目增速模块：列出自己关注的所有项目，快速查看周、月star增速

## 核心服务层（Go 后端・业务逻辑）

- GitHub 认证服务：生成 GitHub OAuth2 授权链接，处理授权码兑换 AccessToken，验证 / 刷新 Token，解析用户信息，登录态校验
- GitHub 数据服务：调用 GitHub API 获取趋势 / 新增项目数据，计算项目增长速率；登录后调用私有 API，未登录仅调用公开 API
- 内容分发服务：接收 GitHub 项目数据并分发给 AI 总结 / 搜索服务，数据格式标准化
- 搜索服务：基于项目关键词调用新闻 / 视频搜索接口，搜索结果去重 / 相似度排序
- 前后端绑定服务：暴露 Go 函数给前端调用，处理前端请求并返回结构化数据
- AI 总结服务：调用 nanobot go 生成项目智能总结，总结文本格式化

## 基础支撑层（通用能力・全栈）

- 配置管理模块：存储 GitHub API Token、AI 服务地址等配置，本地持久化存储用户登录 Token，适配 Windows 环境的配置读取
- 异常处理模块：API 调用失败兜底逻辑，前端错误提示文本统一管理
- 打包分发模块：Wails 打包配置，前端资源编译
- 缓存模块：GitHub 数据本地缓存，搜索结果缓存
