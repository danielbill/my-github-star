## 三、刷新频率控制

### 3.1 内存计时器

使用单个内存计时器控制全局刷新频率：

```go
// App 结构体中的计时器字段
lastRefresh   time.Time  // 上次刷新时间
refreshMutex  sync.Mutex // 并发锁
```

### 3.2 启动时初始化计时器

```
应用启动
    │
    └── autoLoadInitialData()
            │
            ├── 从数据库获取最新 cached_at
            │
            ├── 计算间隔 = 当前时间 - cached_at
            │
            ├── 间隔 >= 1小时 或 无数据
            │   └── 立刻刷新 → 计时器重置为当前时间
            │
            └── 间隔 < 1小时
                └── 不刷新 → 计时器 = 当前时间 - 间隔
                           （即：剩余时间 = 60分钟 - 间隔）
```

示例：
```
cached_at = 11:30，当前 = 12:00
间隔 = 30分钟 < 1小时
→ 不刷新
→ lastRefresh = 11:30（虚拟时间）
→ time.Since(lastRefresh) = 30分钟
→ 剩余等待 = 60 - 30 = 30分钟

cached_at = 10:00，当前 = 12:00
间隔 = 2小时 >= 1小时
→ 立刻刷新
→ lastRefresh = 12:00
→ 计时器从现在开始
```

### 3.3 刷新逻辑

```
触发刷新（手动或自动）
    │
    ├── 检查计时器
    │   │
    │   ├── time.Since(lastRefresh) < 1小时
    │   │   └── 返回缓存数据 + 提示剩余时间
    │   │
    │   └── time.Since(lastRefresh) >= 1小时 或 首次
    │       │
    │       ├── 执行刷新（Trending + UserStarRepo）
    │       │
    │       └── 重置计时器 lastRefresh = now
    │
    └── 返回数据
```

## 五、用户星标仓库处理

### 5.1 数据获取

| 方法                         | 说明                                           |
| ---------------------------- | ---------------------------------------------- |
| `LoadUserStarRepo()`         | 从数据库加载用户星标仓库                       |
| `RefreshUserStarRepo()`      | 从 GitHub API 获取并保存到数据库（有缓存检查） |
| `ForceRefreshUserStarRepo()` | 强制刷新，忽略缓存（登录后调用）               |

### 5.2 stars_since 计算

每次刷新时，对比新旧数据计算星标增长：

```
stars_since = 新 stargazers_count - 旧 stargazers_count
```

示例：
```
旧数据：stargazers_count = 1000
新数据：stargazers_count = 1050
结果：stars_since = 50
```

### 5.3 time_range 计算

记录刷新间隔时长（单位：小时）：

```
time_range = 当前时间 - 旧 cached_at（小时数）
```

示例：
```
旧 cached_at: 2026-02-19 10:00:00
当前时间:     2026-02-19 15:00:00
结果：time_range = 5（小时）
```

## 六、前端调用流程

### 6.1 初始加载

```typescript
// App.tsx - loadInitialData()
const loadInitialData = async () => {
    const result = await LoadTrendingData();
    // 设置 weeklyRepos, monthlyRepos, cacheTime
};

// StarredSidebar.tsx - useEffect
useEffect(() => {
    if (isLoggedIn) {
        loadStarredRepos();  // 调用 LoadUserStarRepo()
    }
}, [isLoggedIn]);
```

### 6.2 手动刷新

```typescript
// Trending 刷新
const handleRefresh = async () => {
    const result = await RefreshTrending();
    // 更新数据
};

// UserStarRepo 刷新
const handleRefresh = async () => {
    const repos = await RefreshUserStarRepo();
    // 更新数据
};
```

### 6.3 登录成功后自动刷新

```typescript
// useAuth.ts - 监听 login-success 事件
EventsOn('login-success', async (userData) => {
    // 1. 先强制刷新星标仓库（忽略缓存）
    await ForceRefreshUserStarRepo();
    
    // 2. 再更新登录状态（触发 StarredSidebar 加载数据）
    setIsLoggedIn(true);
    setUser(userData);
});
```

**重要：** 必须先完成数据刷新，再更新 `isLoggedIn` 状态，否则 `StarredSidebar` 会读取到旧数据。

## 七、数据库表结构

### 7.1 github_trending 表

| 字段             | 类型     | 说明                      |
| ---------------- | -------- | ------------------------- |
| id               | INTEGER  | 主键                      |

| stars_since      | INTEGER  | 增长星标数                |
| html_url         | TEXT     | GitHub 链接               |
| cached_at        | DATETIME | 缓存时间                  |
| time_range       | TEXT     | 时间范围 (weekly/monthly) |
